# Techniques and frameworks in the CIS sessions

Each session carries a library of named techniques. At the steps that use one, the skill offers a few that fit the situation, says why, and lets the user choose or ask for a recommendation. Storytelling chooses one framework for the whole session, and the user can ask to see every framework in a family.

## What each session draws on

- `bmad-cis-design-thinking`: methods for each phase, such as user interviews and empathy mapping, crazy 8s, paper prototyping and wizard of oz, usability testing.
- `bmad-cis-innovation-strategy`: frameworks for disruption, market analysis, business models, value chains, technology, and strategy, such as jobs to be done, blue ocean strategy, five forces, the business model canvas, and three horizons.
- `bmad-cis-problem-solving`: methods for diagnosis, analysis, synthesis, creative work, evaluation, and implementation, such as five whys, fishbone diagrams, force field analysis, TRIZ, and decision matrices.
- `bmad-cis-storytelling`: twenty-five frameworks in five families: transformation (hero's journey, Pixar story spine), strategic (brand, vision, origin), persuasive (pitch, sales, change, fundraising), analytical (data story, case study), and emotional (hook-driven, human interest).

## Answering "which technique should I use?"

Do not pick for the user. Recommend the session that fits and tell them it will offer the techniques that suit their situation. For the full list, read the library file in the installed skill.

## Adding the team's own

The library is a file inside the skill and is replaced on update, so it is not the place for a team's methods. Add them as standing facts through `bmad-customize`: see `help/changing-a-session-or-persona.md`.
